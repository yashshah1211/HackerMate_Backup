HackerMate Developer Setup & Workflow

This guide outlines local installation steps, database migrations, authentication setups, and team-defined contribution workflows.

Step 1: Install Prerequisites

Verify you have the correct software versions installed locally:

  • Git: Distributed version control.
  • Node.js (v20 or newer): Next.js runtime environment.
  • VS Code: Editor of choice with ESLint/TypeScript configurations.
git --version
node -v
npm -v

Step 2: Clone the Repository

git clone <GITHUB_REPO_URL>
cd HackerMate_Backup

Step 3: Install Dependencies

npm install

Step 4: Configure Environment Variables

Create a .env.local file in the root folder and add the following keys:

NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
CRON_SECRET=your_secure_cron_secret
RESEND_API_KEY=re_your_resend_api_key
⚠️
Security Alert: Do not commit .env.local. It contains backend keys bypassing RLS.

Step 5: Apply DB Migrations

Run the Supabase CLI to update the database schema, RPC functions, and RLS policies:

supabase link --project-ref <project-ref>
supabase db push

Step 6: Configure Google & GitHub OAuth

Navigate to Authentication > Providers in your Supabase dashboard and enable Google and GitHub providers with your OAuth credentials.

Step 7: Seed Hackathon Data

Load mock hackathons into the PostgreSQL database to test matchmaking features:

psql -d "postgresql://postgres:[password]@db.[project-ref].supabase.co:5432/postgres" -f seed_unstop_hackathons.sql

Step 8: Start App

npm run dev

Daily Git Workflow

git pull origin main
# Make changes...
npm run lint
npm run build
git add .
git commit -m "feat: description of work"
git push origin main

Troubleshooting

If npm install Fails
Run: rm -rf node_modules package-lock.json && npm install
Database RLS Errors
Ensure you linked the correct project reference and executed supabase db push.
